# 网页图标

此目录由 `node scripts/export-icons.mjs` 从 `menubar/icon/squirrel/` 生成。

- `squirrel.svg`：页面标题旁的彩色品牌标识。
- `favicon-*.png`、`favicon.ico`：浏览器标签页与兼容图标。
- `apple-touch-icon.png`：180px 主屏幕图标。
- `icon-192.png`、`icon-512.png`：Web Manifest 图标。
- `icon-maskable-512.png`：留有安全区的可裁切图标。

不要单独编辑派生文件；调整母版后重新导出。旧文件不自动清理。
