# 动物图标设计探索

此目录保存 Seen 的动物图标方案，供设计比较和后续开发使用。

## 结构与命名

- `prompts-v1.json`：本轮设计说明与实际使用的图像生成提示词。
- `<animal>-app-v<版本>.png`：独立应用图标；`squirrel` 为松鼠，`otter` 为水獭，`swallow` 为燕子。
- `<animal>-status-v<版本>.png`：对应的透明底单色菜单栏图标。
- `*-preview-v<版本>.png`：仅供比较的设计预览，不直接用于构建。
- `delivery-v<版本>.md`：交付文件、尺寸和使用说明。

## 设计原则

- 简洁、灵动，通过动物的轮廓和动作表达收集、留存和回顾所学。
- 本轮独立探索新形象；图形不依赖应用名称。
- 主图标与菜单栏图标分别设计，菜单栏版本以小尺寸辨识度为先。
- 图像由内置 image_gen 生成；提示词保存在本目录。

## 版本与清理

新增方案使用新版本号，不覆盖已有方案。探索文件保留至用户选定；删除旧方案须先获得用户同意。

本目录不参与现有构建。选定方案后再接入 `menubar/Resources` 与 `web/`。
