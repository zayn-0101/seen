## 方向

以「安静的知识书桌」为方向：温暖、清晰、有一点松鼠的灵动，适合长期使用。沿用现有松鼠标识，以暖白和深墨绿为主体，松鼠橘用于关键操作，鼠尾草绿用于正常状态。深色模式使用带绿意的深炭色，单独校准文本、边框和控件对比度。

## 页面

1. **顶部和主要操作**：突出「看过，留下」与视频链接输入；模型状态、轮询开关、轮询间隔、诊断入口清晰可见。
2. **最近总结和实时观察**：总结占主要阅读空间，观察与处理进度放在较紧凑的侧栏；高度随内容调整，减少空白。长内容仍可阅读和滚动。
3. **知识库**：使用层次清晰的列表，保留分类、平台、标题、摘要和点击查看已有历史总结的行为。
4. **设置与反馈**：统一模型设置、诊断、提示、错误、空状态和加载状态的样式；保留键盘可操作性与清晰焦点。
5. **尺寸和外观**：适配宽屏、较窄窗口和手机宽度；深色模式独立调整对比度；动效轻量并遵循减少动态效果的系统设置。

当前页面的手动扫描、强制重生成、间隔保存、开始／暂停轮询、诊断、模型设置、Obsidian 跳转、状态与历史内容等入口均须保留。示意图为表现排版，未画出全部控件；实施时不能据此移除。用户可见文案应与真实状态一致，不根据示意图虚构视频进度、统计或连接状态。

## macOS 菜单栏

统一色彩、间距和卡片层级，保留松鼠标识与当前状态。已有的开始／暂停、网页面板、笔记目录、设置、本周回顾、运行诊断、登录时自动启动、退出、离线与未配置模型提示全部保留。根据内容核查弹窗尺寸，避免状态提示被截断。

## 实施边界

- 主要调整 `web/index.html`、`web/style.css`，仅在维持原有 ID 和行为所需时调整 `web/app.js`；菜单栏主要调整 `menubar/Sources/PanelView.swift`，必要时调整弹窗尺寸。
- 沿用原生 HTML/CSS/JS 与 SwiftUI，本轮不引入运行时依赖，也不依赖外部字体服务。
- 保留现有功能、API、数据来源、笔记与配置；图中的示例内容不写入用户数据。
- 本方案不包含安装或替换当前运行的应用；构建结果保存在工作区。

## 验证

- 浏览器检查浅色、深色与窄屏布局，以及长标题、长总结、空内容、加载、失败和只读等状态。
- 使用隔离的模拟数据检查扫描、强制重生成、轮询、间隔、设置、诊断、历史总结与 Obsidian 链接的现有交互，不修改实际业务数据。
- 执行 `cd core && node --test`；菜单栏调整后执行 `cd menubar && ./build.sh`。
- 检查菜单栏在运行、暂停、离线和模型未配置时的显示，以及文字对比度、焦点、溢出和窗口尺寸。
