## 待审查事项

| 优先级 | 问题与影响 | 建议下一步 |
| --- | --- | --- |
| 高 | **历史字幕可能已发生同名覆盖。** 原实现只按笔记名写入字幕，跨学科同名时会覆盖先前存档。现在新写入会保留副本；重整理会核对归属，有同名记录的无归属旧存档也会被拦下。历史存档是否受影响尚未核实。见 [obsidian.js](../core/lib/obsidian.js) 与 [index.js](../core/lib/index.js)。 | 先制定只读检查，比较状态、字幕的 `notePath`、视频 ID 与现有备份；确认结果后再决定是否恢复。无归属、但状态中只剩一条同名记录的旧存档仍无法保证来源正确。 |
| 中 | **文件系统隔离仍有边界。** [obsidian.js](../core/lib/obsidian.js) 已拒绝 `..` 越出 vault，但没有验证目录中的符号链接最终指向；[vault-access.js](../core/lib/vault-access.js) 的超时不能取消已启动的底层 I/O，超时后旧操作仍可能晚于重试完成。 | 明确是否支持 vault 内指向外部的符号链接；评估真实路径校验和可终止的子进程 I/O，同时处理检查与写入之间的竞态。 |

## 本轮已修复（2026-11-17 审计修复）

- **实例锁原子化**：`core/lib/index.js` 的 `acquireInstanceLock` 用 `open(lockPath, 'wx', 0o600)` 抢占并写入 PID；EEXIST 时探活，失效或损坏的锁清理后重试。拿不到锁的进程进入只读模式，`getStatus()` / `getConfig()` 返回 `readOnly` 与 `readOnlyReason`（`locked-by-other` / `lock-write-failed` / `lock-stale-unlink-failed`），面板状态同步说明原因。
- **存档重整理离线化**：`resummarizeNote` 现在只读 `资料/字幕/<笔记名>.md` 存档，传 `archiveOnly:true` + `prefetchedContent` 给 `processTitle`，不重新抓平台内容、不下载音频、不转写；缺元数据时从原笔记和状态补齐。
- **状态路径归一化**：新增 `core/lib/paths.js` 的 `normalizeAuxRelPath` / `normalizeStateAuxPaths`，启动时修正旧字幕路径；`scripts/migrate-vault.mjs --state-only` 可单独修状态（写回前先备份 state.json）；`scripts/self-check.mjs` 增加字幕路径缺失/遗留检查。
- **供应链校验**：ffmpeg-static 固定 `b6.1.1` 并在 `core/lib/whisper.js` 内置各平台 SHA256，不匹配中止；yt-dlp 的 `SHA2-256SUMS` 只从官方取得，镜像下载必须有官方校验；`menubar/build.sh` 下载 Node 运行时后用 `SHASUMS256.txt` 校验。
- **搜索可见性**：`core/lib/vault-search.js` 新增 `searchVaultDetailed`，返回 `{ results, scanned, skipped, truncated }`；中文查询用 `Intl.Segmenter('zh')` 分词；面板提示截断和跳过数量。
- **学科上限**：`core/lib/subject.js` 达到 12 个学科且没有相似学科时归入「未分类」，不再强行塞进某个已有学科；`resolveSubjectName(subject, existing, { maxSubjects })` 透传上限。
- **本机 API 防护**：`server/index.js` 的所有请求始终校验 Host（本机名 + 实际绑定地址），防 DNS rebinding；删除兼容用的 `GET /api/llm/models`，只保留 POST，避免自带密钥出现在 URL。
- **保存失败可见**：`save()` 返回布尔值，状态保存失败时笔记仍然返回，但 `warnings` / `stateSaved` 会带给调用方和 SSE；学习手册、课程总览、字幕存档失败也逐项收集警告。
- 同步更新 `README.md`、`CLAUDE.md`、`docs/architecture.md`、`docs/contracts.md` 中关于实例锁、供应链校验、搜索、学科上限和存档重整理的说明。
