# 拾影 Seen 项目审查

审查从 2026-11-18 开始，2026-11-25 完成复验。分支为 `codex/project-audit-20261118`，起点为 `main` 的 `b74610c`。范围覆盖核心引擎、独立服务、网页、菜单栏、维护和构建脚本、测试、品牌资源与仓库文档。涉及读写的验证均使用临时笔记库和模拟模型。

## 后续修复

| 发现 | 处理结果 |
| --- | --- |
| 维护脚本和服务同时写入会丢状态 | 写入型维护按服务的状态目录取得实例锁，再读状态和笔记，并将锁保留到最后一次写入结束。服务运行时会明确提示占用，预演可以照常执行。[实例锁](../core/lib/instance-lock.js) · [维护说明](../README.md) |
| 同一视频重生成时可能因学科变化产生重复笔记 | 沿用原学科和路径，保留手写补充、复习进度和字幕存档。历史重复项按平台身份在知识库列出，多篇并存时由用户指定需要重整的笔记。原文件分别保留。[整理引擎](../core/lib/index.js) · [网页](../web/app.js) |
| mnemon 的默认值有两种 | 默认关闭。已保存的明确偏好继续生效，开启后的新摘要立即按设置写入。`SEEN_DISABLE_MNEMON=1` 的优先级最高。[服务](../server/index.js) |
| 状态损坏后缺少固定的恢复来源 | 自动保留最近两份有效状态，恢复命令可预览，执行恢复时先原样留存当前文件。缺少有效备份时，Markdown 仍可提供正文和部分元数据，完整状态依赖备份。[状态存储](../core/lib/state.js) · [恢复命令](../scripts/restore-state.mjs) |
| 连续整理会重复重建派生页面 | 自动队列和批量整理在完成后合并重建，只更新受影响的学科手册。退出自动收录的概念页和主题页更新 AUTO 区，保留路径与手写内容。[页面重建](../core/lib/rebuild.js) |

后续验证通过 389 项测试、116 个 JavaScript 文件语法检查和 macOS 轻量构建。隔离服务实测了写入型维护拒绝并发、原文件保留后恢复、重生成保留手写补充，以及同批只重建一次索引。浏览器验证覆盖 1280 像素浅色和 390 像素深色。

此前关于历史字幕归属、文件写入超时后的恢复，以及构建备份保留的审查记录可单独查阅。[上次审查](audit-2026-11-17.md)

## 首轮已修复

- **整理和重试**。自动识别、手动扫描、失败重试和历史重整共用一个有上限的队列。等待期间保留失败记录，停止轮询后仍会执行已经提交的手动请求。切走窗口会中断连续识别计数，已停止的轮询会忽略迟到的观察结果。[引擎](../core/lib/index.js) · [队列](../core/lib/process-queue.js)
- **笔记保护**。已有状态文件无法读取或 JSON 损坏时，服务进入只读，读取状态的维护命令报告失败。两条同名 B 站视频的 BV 编号仅大小写不同时，会各自保留笔记。强制重写前读取原文失败时会中止，保护手写补充。[状态读写](../core/lib/state.js) · [视频身份](../core/lib/source.js) · [笔记写入](../core/lib/obsidian.js)
- **模型和更新**。手填模型 ID、环境配置和保存后的实际模型请求保持一致。保存设置采用原子替换。检查更新遇到上游失败会显示错误并允许重试，成功结果才进入缓存。[服务](../server/index.js) · [模型客户端](../server/llm.js) · [网页](../web/app.js)
- **网页和笔记阅读**。修复窄屏筛选栏横向溢出、输入法确认和多行输入误提交、历史重刷按钮无法恢复、自动保存后知识库列表未刷新。修正 Obsidian 索引表格的双链分隔符，以及旧笔记积压超过 100 篇时漏列本周复习项的问题。[网页](../web/app.js) · [样式](../web/style.css) · [索引](../core/lib/index-note.js) · [周回顾](../core/lib/review.js)
- **菜单栏和构建**。菜单栏定时刷新只请求自己展示的状态，使用与服务一致的本机地址。自检输出可解析的 JSON，连接或响应异常时返回失败退出码。构建缓存按 Node 版本区分，分发包省去开发仓库路径，脚本校验最终签名。[菜单栏客户端](../menubar/Sources/ServiceClient.swift) · [自检](../menubar/Sources/main.swift) · [构建脚本](../menubar/build.sh)
- **维护脚本**。重打标签先校验模型输出，写入时逐篇备份和保存状态，三份索引写完才报告成功。索引失败可再次运行补齐。非法数量参数会报错。重建预演与实际写入共用建页规则，README 已校正状态备份位置。[重打标签](../scripts/retag-notes.mjs) · [知识库维护](../scripts/maintain-vault.mjs) · [回归用例](../core/test/retag-notes.test.js)
